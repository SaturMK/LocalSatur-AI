LocalSatur AI

Local-first AI coding agent for Visual Studio Code, powered by Ollama.

LocalSatur AI lets you work with AI directly inside VS Code while keeping your development workflow close to your local machine.

Features

Local AI coding assistance with Ollama

Chat with your coding agent

Agent mode for development tasks

Workspace-aware file access

File attachments

Workspace file selection

Whole-file edit proposals

Review proposed changes before applying them

Apply or reject file changes

Multiple AI provider support

OpenAI-compatible provider support

Streaming AI responses

Configurable AI model and context length

AI Providers

LocalSatur AI currently supports:

Ollama

OpenRouter

NVIDIA NIM

Requesty

Other OpenAI-compatible providers can be integrated through the provider architecture

Requirements

Visual Studio Code

Node.js

Ollama for local AI models
